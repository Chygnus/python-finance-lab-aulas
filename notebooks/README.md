# Notebooks

Um arquivo por aula, sempre com o nome `Aula_NN.ipynb`. A lista completa, com o assunto de cada aula, está na [página inicial do repositório](../README.md).

- **Para ver o conteúdo:** clique no arquivo. O GitHub mostra o notebook direto no navegador, com os gráficos.
- **Para baixar:** abra o arquivo e clique em **Download raw file** (a setinha para baixo, no canto direito).
- **Para rodar sem instalar nada:** use o botão **Open in Colab** na tabela da página inicial.

Os notebooks baixam os dados da internet quando você roda, por isso precisam de conexão. A aula 10 cria sozinha um arquivo `financas.py` na mesma pasta, e a aula 7 salva arquivos `.csv` com os candles. Isso é esperado.
